# Módulo 14 — Mensageria Omnichannel & WhatsApp API

## Visão Geral
O módulo `14-modulo-mensageria-whatsapp/` é responsável pelo envio de notificações e lembretes aos pacientes via WhatsApp (Meta Cloud API / Baileys), garantindo a confirmação de agendamentos, envio de laudos e pesquisa de satisfação NPS.
