Desenvolvimento & Deploy

Como Rodar o Núcleo Localmente

O sistema completo com suporte a SSR e API Routes roda a partir da pasta nucleo/.

bash / powershell
# 1. Clonar o repositório oficial
$ git clone https://github.com/tiscinovacoes/hospital-360.git
$ cd hospital-360/nucleo

# 2. Instalar dependências (Node 20+ LTS recomendado)
$ npm install

# 3. Iniciar o servidor de desenvolvimento
$ npm run dev

# Acesse no seu navegador: http://localhost:3000
