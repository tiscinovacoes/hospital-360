# Módulo 07 — Fintech Hospitalar & Split de Pagamentos

## Visão Geral
O módulo `07-modulo-fintech-split/` realiza a divisão automática de pagamentos (*Payment Split*) no momento da liquidação financeira do atendimento hospitalar ou consulta médica.

## Divisão de Split
- **Parcela Hospital**: Cobre diária, insumos, taxa de sala e taxa de uso de equipamentos.
- **Parcela Corpo Médico**: Repasse líquido direto da consulta ou honorário cirúrgico.
- **Parcela Laboratório/Diagnóstico**: Repasse das taxas de exames LIMS.

## Execução Local
```bash
docker-compose up -d
```
