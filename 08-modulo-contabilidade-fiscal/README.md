# Módulo 08 — Contabilidade Fiscal & Emissão NFSe

## Visão Geral
O módulo `08-modulo-contabilidade-fiscal/` automatiza o faturamento fiscal do hospital, emitindo Notas Fiscais de Serviços Eletrônicas (NFSe) e Notas Fiscais de Produto (NFe para insumos), apurando retenções federais (PIS, COFINS, CSLL, IRRF) e municipais (ISS).
